刚学 Rust 时被借用检查器折磨了很久，后来发现只要记住三条规则，大部分报错都能看懂。

## 三条规则

1. 每个值都有一个所有者。
2. 同一时刻只有一个所有者。
3. 所有者离开作用域，值就被释放。

## 移动

```rust
let a = String::from("hello");
let b = a;          // 所有权移动到 b
println!("{}", a);  // 编译错误：a 已经不能用了
```

`String` 的数据在堆上，赋值时不会复制，只是把所有权交给 `b`。整数这类实现了 `Copy` 的类型则会直接复制。

## 借用

不想交出所有权，就借用：

```rust
fn len(s: &String) -> usize {
    s.len()
}

let s = String::from("hello");
let n = len(&s);    // 借出去，s 依然可用
```

借用也有规矩：同一时刻，要么有任意多个不可变引用，要么只有一个可变引用。这条规则在编译期就排除了数据竞争。

> 报错的时候先问自己：这个值现在归谁？我是想交出去，还是只是借来看看？
