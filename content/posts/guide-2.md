## 打开编辑器

- 写新文章：在后台点右下角的「写博客」，或者进入「写作 → 博客」点「写新博客」。
- 修改文章：在后台打开这篇文章，点标题下方的「编辑」，或者在「写作 → 博客」的列表里点「编辑」。

## 编辑器里的各个部分

从上到下依次是：

- **标题**：必填。
- **标签**：用逗号、顿号或空格分开。开头的 # 会自动去掉，重复的只留一个，最多 8 个。
- **摘要**：选填。不写的话，列表里会自动截取正文开头约 90 个字。
- **系列与置顶**：点开后可以填所属系列、勾选置顶，用法见本系列第三篇。
- **编辑和预览**：两个标签页来回切换，预览就是发布后的样子。
- **格式按钮**：标题、粗体、斜体、行内代码、代码块、提示框、链接、列表、引用、图片。先选中文字再点按钮，格式会加在选中的文字上。
- **正文**：用 Markdown 写。
- **底部**：左边是字数，右边是「存草稿」和「发布」。修改已经发布的文章时，这两个按钮叫「转为草稿」和「发布更新」。

## 草稿与发布

- **存草稿**：把文章提交到仓库，但不出现在网站上。草稿存在仓库里，换一台设备打开后台也能接着写。
- **发布**：文章出现在网站上，大约 1–2 分钟后上线。草稿第一次发布时，文章日期会改成发布的那一天。
- **转为草稿**：把已经发布的文章从网站上撤下来，内容保留。

> [!WARNING]
> 仓库是公开的，存在仓库里的草稿，别人去翻仓库也能看到。不想公开的内容，先别点「存草稿」。

> [!TIP]
> 编辑器还会在你停下来不到一秒时，把正在写的内容自动存在这台设备上，右上角显示保存时间。没来得及点按钮就退出了，下次打开编辑器会提示恢复。

## Markdown 基础

```markdown
## 二级标题
### 三级标题

**粗体**  *斜体*  `行内代码`

- 无序列表
1. 有序列表

[链接文字](https://example.com)

> 引用

| 表头 | 表头 |
|---|---|
| 内容 | 内容 |
```

单独一行写三个减号 `---` 是分隔线。正文里换一行就是换行，空一行是新段落。外部链接会在新窗口打开。

> [!NOTE]
> 文章里有两个以上的二级或三级标题时，开头会自动生成目录。

## 图片

点「图片」按钮选择照片。照片会先在手机上压缩，长边不超过 1280 像素，大小一般在 200KB 以内，然后在正文里插入这样一行：

```markdown
![图片说明](img:xxxx)
```

把「图片说明」改成真正的描述，读者全屏看图时会显示在图片下方。删掉这一行，图片就从文章里去掉了；通过后台提交内容时，不再使用的图片会自动清理掉。其他文章、仓库草稿或这台设备的本机暂存仍在引用的图片会保留；如果刚放弃一份暂存，图片会在下次提交内容时再检查清理。

## 提示框

在引用的第一行写上类型，就会变成带颜色的提示框：

```markdown
> [!TIP]
> 这里写内容
```

| 写法 | 显示的标题 | 适合 |
|---|---|---|
| `[!NOTE]` 或 `[!说明]` | 说明 | 补充信息 |
| `[!TIP]` 或 `[!提示]` | 提示 | 技巧建议 |
| `[!IMPORTANT]` 或 `[!重要]` | 重要 | 必须知道的事 |
| `[!WARNING]` 或 `[!注意]` | 注意 | 需要小心的操作 |
| `[!CAUTION]` 或 `[!警告]` | 警告 | 可能造成损失的操作 |

方括号后面写文字，会替换默认标题，比如 `> [!TIP] 小技巧`。工具栏的「提示框」按钮会直接插入一个模板。

> [!IMPORTANT] 效果预览
> 这就是一个 IMPORTANT 提示框，标题被替换成了「效果预览」。

## 代码块

三个反引号开头、三个反引号结尾。第一行写语言，空一格再写文件名：

````markdown
```python hello.py
print("hello")
```
````

显示出来是这样：

```python hello.py
print("hello")
```

- 文件名也可以写成 `title="hello.py"`。
- 5 行以上的代码自动显示行号，点「复制」时不会带上行号。
- 超过 24 行的代码默认折叠，读者点「展开全部」查看。
- 语言写 `diff` 时，`+` 开头的行标绿，`-` 开头的行标红：

```diff
-print "hello"
+print("hello")
```

## 发布之后

- 文章页标题下方显示发布日期和字数。发布一天以后又修改过，会多显示「更新于某天」。
- 超过一年没有更新的文章，开头会提示「内容可能已经过时」。
- 删除文章：在「写作 → 博客」的列表里点「删除」，确认后提交，网站上的这篇文章随之消失；仓库的历史记录里还能找回。
