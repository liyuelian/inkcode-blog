这个网站的文章、小说和设置都保存在 GitHub 仓库里。你在手机后台点「发布」，一两分钟后所有访客看到的就是新版本。

## 在手机上发文

1. 用手机打开后台（网站地址后面加 `/admin/`），第一次使用时连接 GitHub。
2. 点右下角的「写博客」，或者进入「写作」页面。
3. 写好标题和正文，点「发布」。大约 1–2 分钟后，新文章就上线了。

写到一半可以点「存草稿」，换一台设备也能接着写。

## 写作格式

博客正文支持 Markdown。编辑器上方的按钮可以一键插入标题、**粗体**、`行内代码`、链接和图片，图片会自动压缩。

> 小说章节不需要任何格式：直接分段写，一行就是一段。单独一行写 `***` 会变成场景分隔符。

代码块会按语言自动高亮：

```python
def fib(n: int) -> int:
    """返回第 n 个斐波那契数"""
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```
