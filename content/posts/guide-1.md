## 这个网站是怎么运作的

网站托管在 GitHub Pages 上，不需要自己的服务器。文章、小说和设置都是 GitHub 仓库里的普通文件：文章在 `content/posts`，小说在 `content/novels`，图片在 `static/images`。

你在手机后台点「发布」，后台会把改动提交到仓库；GitHub 随后自动生成整个网站并上线，大约需要 1–2 分钟。

> [!NOTE]
> 提交之后，后台底部会显示「正在生成网站」，完成后变成「已上线」，点「查看网站」就能看到。

## 手机后台

后台的地址是网站地址后面加上 `/admin/`。第一次打开时，填上 GitHub 仓库和访问令牌，点「连接」，以后这台设备就不用再填了。

> [!TIP]
> 把后台添加到手机桌面，以后像 App 一样一点就开。iPhone 用 Safari 打开后台，点分享按钮，选「添加到主屏幕」；安卓用 Chrome 打开，在菜单里选「添加到主屏幕」或「安装应用」。

后台里能看到和网站一样的页面，相当于预览，另外还多了这些东西：

- 导航栏里的「写作」，点进去是管理页面。
- 右下角的写作按钮：在首页和博客页是「写博客」，在小说列表是「新建小说」，在某部小说的页面是「写新章」。
- 文章和章节标题下方的「编辑」。
- 草稿也会显示出来，带「草稿」标记。

公开的网站上没有任何编辑入口。

## 网站的导航

| 入口 | 内容 |
|---|---|
| 网站名称 | 回到首页：介绍、最新 4 篇文章、全部小说 |
| 博客 | 全部文章，可以按标签筛选 |
| 小说 | 全部作品 |
| 归档 | 写作热力图，以及按年月整理的全部文章和章节 |
| 放大镜图标 | 搜索全部文章、小说和章节 |
| 太阳或月亮图标 | 切换日间或夜间模式 |

页面底部还有 RSS 订阅地址。

## 第一次使用建议做的事

1. 打开后台，连接 GitHub。
2. 进入「写作 → 设置」，改网站名称、介绍和风格。
3. 写第一篇文章：点右下角的「写博客」。
4. 把网站地址发给想看的人。

> [!TIP]
> 每篇文章、每一章都有自己的网址，比如 `https://你的网站/posts/文章编号/`，可以单独分享，发到聊天软件里还会显示标题和摘要。
